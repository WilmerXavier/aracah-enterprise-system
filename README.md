# ARACAH Enterprise Management System

Enterprise management system developed for a furniture-sector company, built as an applied academic project at the National Autonomous University of Honduras (UNAH).

Status: documentation published. Source code pending upload and review.

## 1. Introduction

ARACAH is a web application designed to support business process management for a company in the furniture sector. It was developed collaboratively by a team of students as part of an applied academic project.

## 2. Context

The organization required a software solution to support the management of business processes through a web application. The project was completed as part of the Administrative Informatics program at UNAH.

## 3. Objective

Design and develop a web system that supports business process management through different functional modules, working collaboratively within an applied academic environment for a real organization.



## 4. Technologies

Frontend: React, HTML, CSS, JavaScript. Backend: Node.js. Database: SQL, MySQL.

## 5. My Role
