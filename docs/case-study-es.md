# Caso de Estudio: ARACAH Enterprise Management System

Version 1.0 - Estado: Borrador validado con informacion confirmada

## 1. Resumen Ejecutivo

Desarrollo colaborativo de un sistema de gestion empresarial para una empresa del sector mueblero, realizado como proyecto academico aplicado en la Universidad Nacional Autonoma de Honduras (UNAH).

El proyecto tuvo como objetivo contribuir a la digitalizacion de procesos operativos mediante una aplicacion web orientada a la administracion de informacion empresarial.

Mi participacion se centro principalmente en el desarrollo del Modulo de Inventarios, colaborando ademas en otras funcionalidades del sistema como parte de un equipo de desarrollo.
